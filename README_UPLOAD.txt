LAM HỒNG ICT WEBSITE V5 ULTIMATE - BẢN FLAT

Upload:
1. Giải nén ZIP.
2. Vào GitHub repository.
3. Add file > Upload files.
4. Chọn toàn bộ file bên trong và kéo thả.
5. Khi GitHub hỏi file trùng, xác nhận thay thế.
6. Commit trực tiếp vào main.
7. Không xóa thư mục .github/workflows.

Sau deploy:
- Mở https://www.lamhongict.com
- Nhấn Ctrl + F5
- Kiểm tra trang chủ, menu, Dark Mode, Zalo và form liên hệ.
