LAM HỒNG ICT – WEBSITE TỐI GIẢN CHO MICROSOFT PARTNER

CÁCH XEM THỬ
1. Giải nén tệp ZIP.
2. Mở index.html bằng trình duyệt.

CÁCH ĐƯA LÊN CLOUDFLARE PAGES
1. Đăng nhập Cloudflare.
2. Vào Workers & Pages → Create → Pages → Upload assets.
3. Tải thư mục chứa index.html và styles.css lên.
4. Sau khi website hoạt động, vào Custom domains.
5. Thêm lamhongict.com hoặc www.lamhongict.com.
6. Làm theo hướng dẫn DNS của Cloudflare.
